New in v1.0

Answers that look the way they should.

Writing rarely fits in one plain paragraph. Anywhere AI now understands markdown and renders it — bold, italics, numbered steps, bullet points, checklists, code and a well-placed emoji.

Preview the formatted answer, switch to Edit for the raw markdown, and copy clean text when you are done. Formatting is a presentation layer — your pasted result stays tidy.

  • Clean plain text for copy & replace

            Install guide
            
Up and running in four steps.

            

              Version 1.0.2
              195 MB
              Windows 10 & 11 · 64-bit
            

          

          
        


        

          
    
            
  1. 
              01
              
    
                
    Download the installer
    
                
    
                  Grab the installer below. If your browser asks what to do with the file, choose
                  Save or Keep.
                
    
                
                  
                  Anywhere AI-Setup-1.0.2.exe
                  195 MB
                
              
    
            
    2. 
            
  2. 
              02
              
    
                
    Run the installer
    
                
    
                  Double-click the downloaded file. Setup installs for your Windows user only, so
                  no admin rights are needed. On the options screen you can keep a
                  desktop shortcut, add Start with Windows, and let
                  setup launch the app when it finishes.
                
    
                
    
                  
                  
    
                    If Windows shows “Windows protected your PC”
                    
    
                      This build is not code-signed, so SmartScreen may warn you. Click
                      More info, then Run anyway. Some antivirus
                      tools flag unsigned installers too — only run the file if you downloaded it
                      from this page, and use the SHA-256 check below if you want to be sure.
                    
    
                  
    
                
    
              
    
            
    3. 
            
  3. 
              03
              
    
                
    Open Settings and add your API key
    
                
    
                  Click the Anywhere AI icon in the system tray and open Settings.
                  Choose your provider, paste its API key, check the model name, then click
                  Save — the app tests the connection and tells you whether the key
                  and model both work.
                
    
                
    
                  No key yet? Get API key in Settings opens that provider's page.
                  Provider usage is billed by them, separate from any chat subscription. Keys are
                  encrypted and stay on this PC.
                
    
              
    
            
    4. 
            
  4. 
              04
              
    
                
    Select text and press Ctrl + Shift + A
    
                
    
                  In any app — email, docs, a browser — select the text you want to change and press
                  the shortcut. Type an instruction such as “make this shorter”, then press
                  Send, or just press Enter to rewrite the selection.
                
    
                
    
                  Change the shortcut any time in Settings → Shortcuts; it is saved
                  instantly.
                
    
              
    
            
    5. 
          


          

            
Good to know

            
    
              
  • 
                It lives in the tray. The shortcut works while the app is running.
                Closing the assistant window just hides it; to quit completely, right-click the
                tray icon and choose Quit.
              
    • 
              
  • 
                Your text stays yours. Selected text is sent only when you press
                Send, directly to the provider you picked. API keys never leave your PC.
              
    • 
              
  • 
                Updating. Download the newest installer from this page and run it
                again — your settings stay in the same Windows profile.
              
    • 
              
  • 
                Uninstalling. Windows Settings → Apps → Installed apps →
                Anywhere AI → Uninstall.
              
    • 
              
  • 
                Something to report? Use Send feedback inside the
                app, or the feedback form on this page.
              
    • 
            


            

              Verify the download (optional)
              
Compare the SHA-256 of the file you downloaded with this value:

              
              
In PowerShell, run:

              Get-FileHash ".\Anywhere AI-Setup-1.0.2.exe" -Algorithm SHA256
            


            

              Shortcut or connection not working?
              
    
                
  • 
                  Nothing opens on the shortcut: another app may own
                  Ctrl + Shift + A. Pick a different one in
                  Settings → Shortcuts.
                
    • 
                
  • 
                  “Invalid API key”: copy the key again from the provider dashboard,
                  with no extra spaces.
                
    • 
                
  • 
                  “Invalid model name”: reset the model to the app default or paste
                  the exact name from the provider's documentation.
                
    • 
                
  • 
                  No selected text appears: click inside the text and select it
                  again; a few apps block automated copying.
